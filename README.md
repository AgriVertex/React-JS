# DevTrack – Developer Productivity Dashboard

A professional React + Vite productivity dashboard designed as a GitHub portfolio project.

## Features

- Responsive dashboard UI
- Task CRUD-style interactions
- Task search and filtering
- Priority badges
- Project progress cards
- Analytics chart with Recharts
- Dark/light mode
- LocalStorage persistence
- React Router navigation
- Reusable components
- Clean folder structure

## Tech Stack---

React, Vite, React Router, Recharts, Lucide React, CSS, LocalStorage.

## Run locally--

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

DevTrack is a modern developer productivity dashboard built with React.js and Vite. It provides task management, project tracking, productivity analytics, responsive UI, theme switching, and browser persistence in a clean, reusable architecture.
